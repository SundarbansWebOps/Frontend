# Landing page concepts

Five replacement first-viewport mockups generated with the built-in imagegen tool. No design is approved. Only the home hero is in scope; no Study Corner section or search UI. Source identity: sundarbans-divya crest and house name. The sundarbans-50-designs folder was excluded after user correction and moved to Trash on request, along with rejected initial images. Generated scenery is illustrative, not verified photography of the Sundarbans.

All five images were visually inspected. Static images do not demonstrate motion. Intended implementation motion, subject to selection: short opacity transition and restrained hover feedback, honoring reduced motion. No website source was changed.
